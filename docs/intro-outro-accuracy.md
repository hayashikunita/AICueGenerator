# イントロ・アウトロ候補の境界確認

確認日：2026-10-25。解析エンジン：0.3.1。

対象は「目的から選ぶ」で生成するイントロ・アウトロの始まり／終わりです。
既存Cueの書き換え、rekordboxの再解析、XMLの取り込みは行っていません。

## 変更

- 曲の音量分布の90パーセンタイルを基準に、相対約−50dBと絶対値0.0001の大きい方で有音拍を探します。RMS計算上の微小値は無音として扱います。
- 3拍以内に2拍以上の有音拍があることを条件にし、孤立した曲頭・曲末の音を区間から外します。1拍おきの打楽器は保持します。
- Intro／Outroラベルを優先し、その区間内で継続する有音部分に候補を限定します。終端は保存済みの小節頭だけを使います。
- ラベルなしのイントロ終端・アウトロ先頭は信頼度順で表示し、推定の信頼度は50以下に制限します。同じ小節頭へ揃った候補は重複させません。
- 解析エンジンの版を更新し、古い解析結果のキャッシュと分離します。過去の候補・採用状態は保持します。

## 検証

追加13ケースを含むバックエンド全227件が通過しました。既存のStarlette/httpxの非推奨警告は1件あります。

追加ケースは、主区間より40dB小さいイントロ、曲頭・曲末の孤立クリック、静かなフェード、1拍おきの打楽器、無音・非数値、フレーズ保持、可変テンポと拍ずれ、候補順位、終端の重複を含みます。実波形から特徴量を抽出するクリック付き音源でも境界を確認しました。

読み取り専用で以下の3曲を解析し、生成した9候補すべてが取得済みグリッドの小節頭と一致しました。

| 曲 | 8小節単位で生成した候補数 |
| --- | --- |
| Lottery 4.0 (Dirty) | 3 |
| Perfect Timing (Intro Clean) | 2 |
| Reggae Is Our Music (Intro Clean) | 4 |

8小節の区切りが区間内にない終端は生成せず、1小節など短い単位への変更を案内します。

これは境界の回帰テストとグリッド整合の検証です。実曲の正解位置との比較・試聴による正解率は未測定です。短い単発音が音楽的に意味を持つ曲や、継続的なノイズ、誤ったフレーズラベルは個別確認が必要です。
